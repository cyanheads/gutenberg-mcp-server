# 0.3.4 — 2026-11-21

## Added

- **Creator names and alternative titles.** Mirror `query` matches alternative titles, and `author` matches words within one creator’s name and aliases. `gutenberg_get_book` returns alternative titles, author aliases, and cataloged English Wikipedia links ([#44](https://github.com/cyanheads/gutenberg-mcp-server/issues/44)).
- **Contributor credits.** `gutenberg_get_book` returns role-tagged credits such as illustrators. Search the mirror by a credited name with `contributor` ([#45](https://github.com/cyanheads/gutenberg-mcp-server/issues/45)).
- **Tables of contents.** `gutenberg_get_book` returns the catalog’s `contents` with source line breaks. Search the mirror by a literal phrase with the `contents` filter ([#46](https://github.com/cyanheads/gutenberg-mcp-server/issues/46)).
- **Media type.** Search and browse rows report `media_type` from either catalog. The mirror can filter by exact case-insensitive types such as `["Sound"]` ([#47](https://github.com/cyanheads/gutenberg-mcp-server/issues/47)).
- **Catalog provenance.** Search, browse, and detail report `catalogSource` and `catalogAsOf`. Sources are `mirror` for local SQLite, `live` for Gutendex, and `rdf` for per-book RDF. The date is the last recorded bulk archive checkpoint when available ([#52](https://github.com/cyanheads/gutenberg-mcp-server/issues/52)).
- **Edition metadata.** `gutenberg_get_book` returns the ebook’s `release_date`, `source_imprint`, and `reading_ease` when cataloged ([#55](https://github.com/cyanheads/gutenberg-mcp-server/issues/55)).
- **Library of Congress Classification.** Search, browse, and detail return `lcc`. The mirror accepts case-insensitive code prefixes on search and browse ([#62](https://github.com/cyanheads/gutenberg-mcp-server/issues/62)).

## Changed

- **Mirror schema v6** adds nullable metadata without reharvesting. Existing rows retain their data and checkpoint. New RDF fields populate as rows are harvested.
- **`gutenberg-guide` skill** 1.3 → 1.4 covers the new filters, edition metadata, and catalog provenance.
