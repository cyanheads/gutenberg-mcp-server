# 0.3.2 — 2026-10-31

## Changed

- **Tool guidance** corrects summary provenance and ordering, topic examples, character-limit wording, and unsupported PDF/TeX format examples ([#53](https://github.com/cyanheads/gutenberg-mcp-server/issues/53)); gutenberg-guide 1.2 documents matching and readability boundaries.

## Fixed

- **Catalog matching** ignores accents and expands ligatures in mirror query, translator, and topic searches; existing mirrors migrate without harvesting ([#41](https://github.com/cyanheads/gutenberg-mcp-server/issues/41)).
- **Book titles** normalize MARC subfield markers across stored, RDF, and live records while preserving literal dollar signs ([#49](https://github.com/cyanheads/gutenberg-mcp-server/issues/49)).
- **`gutenberg_get_text`** shares a 50-second upstream allowance with catalog resolution, allowing slow downloads to finish without a 30-second restart and distinguishing deadline expiry from transient failures ([#42](https://github.com/cyanheads/gutenberg-mcp-server/issues/42)).
- **Cache writes** return fetched catalog or text data after a rejected write while preserving caller cancellation ([#50](https://github.com/cyanheads/gutenberg-mcp-server/issues/50)).
- **`is_readable`** identifies eligible Text formats and excludes HTML audio indexes; it does not guarantee mirror-file availability ([#48](https://github.com/cyanheads/gutenberg-mcp-server/issues/48)).
- **Discovery notices** use supplied filters and source-aware language guidance, identify unmatched filtered IDs on complete first pages, and stop suggesting higher browse limits at the cap ([#51](https://github.com/cyanheads/gutenberg-mcp-server/issues/51)).
- **Discovery inputs** normalize MIME type/subtype casing while preserving parameter suffixes, and explain the expected language-code form for overlong items ([#56](https://github.com/cyanheads/gutenberg-mcp-server/issues/56)).
