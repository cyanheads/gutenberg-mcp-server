# 0.3.0 — 2026-10-29

## Added

- **`gutenberg-guide` skill**, published from root `skills/` and served over MCP through the Skills extension: `resources/list` gains `skill://gutenberg-guide/SKILL.md` and the `skill://{+path}` template. It covers deciding whether a book can be read, ruling out search blind spots (accents, translators, translated titles) before calling a book missing, finding openings and chapters past front matter, paging long texts, and ranking editions. It also ships in the npm package, the Docker image, the `.mcpb` bundle, and plugin installs.

## Changed

- **`gutenberg_get_text` description** says front matter (producer credits, title page, contents, prefaces) stays in the returned text; it no longer claims the response holds only the literary work.
- **Server instructions** say to read `is_readable` on each result row (it is not a search argument), note that search rows already carry it, and point to the `gutenberg-guide` skill.
- **Framework** `@cyanheads/mcp-ts-core` ^0.13.15 → ^0.13.18:
  - A tool call the client cancels settles as `RequestCancelled` (`-32011`) even when the handler finishes afterwards (0.13.16, cyanheads/mcp-ts-core#753).
  - HTTP shutdown answers `503` with `Retry-After: 1` while draining, instead of a `500` (0.13.16, cyanheads/mcp-ts-core#749).
  - An out-of-range framework timer or count variable now stops startup, and the banner names the variable (0.13.16, cyanheads/mcp-ts-core#747, cyanheads/mcp-ts-core#746).
  - Tool error text in `content[]` escapes Markdown punctuation (0.13.16, cyanheads/mcp-ts-core#760). This server's own error messages contain none, so every error response probed renders unchanged.
  - MCP SDK `@modelcontextprotocol/server` ^2.3.1 → ^2.4.0 (0.13.17).
- **`.mcpb` bundle** no longer carries mcp-ts-core's `changelog/`, `templates/`, `scripts/`, and `CLAUDE.md`, or `better-sqlite3`'s `deps/` and `src/` C sources (0.13.18 `clean-mcpb`, cyanheads/mcp-ts-core#791). It keeps the MCP SDK's `dist/ext/skills/` runtime the Skills extension loads, through a local fix to the agent-doc selector in `scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts` (cyanheads/mcp-ts-core#794).
- **Packaging**: `.mcpbignore` lists root paths anchored, re-including the catalog-mirror lifecycle scripts under `/scripts/*`; root Agent Plugins 1.0.0 `plugin.json` and `mcp.json` added; the Docker image copies `skills/`.
- **README**: Getting started leads with `claude mcp add` for the hosted and local server; Docker and source builds move under Running the server.
