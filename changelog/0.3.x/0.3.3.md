# 0.3.3 — 2026-11-11

## Added

- **`gutenberg-mcp-server mirror init|refresh|verify`** ([#43](https://github.com/cyanheads/gutenberg-mcp-server/issues/43)) runs the catalog mirror lifecycle from the compiled entry under Node or Bun, e.g. `npx -y @cyanheads/gutenberg-mcp-server mirror init`. Each run prints the resolved `mirror path:` first; `mirror verify` with no mirror at that path exits 1 and creates nothing. The `mirror:*` package scripts run `bun ./dist/index.js mirror <action>` (build first), and `scripts/catalog-mirror-*.ts` and `tsconfig.runtime.json` are gone.

## Changed

- **Default mirror path** is `$XDG_DATA_HOME/gutenberg-mcp-server/gutenberg-catalog.sqlite` (`~/.local/share` when unset, empty, or relative) ([#43](https://github.com/cyanheads/gutenberg-mcp-server/issues/43)). An existing `./.mirror` is read only when `GUTENBERG_MIRROR_PATH` points at it; the Docker image pins its path, so container deployments are unaffected.
- **Book lookups** the local mirror can't answer read the per-book RDF record from the content mirror instead of Gutendex; an RDF 404 is an authoritative `not_found`. Gutendex serves search and popularity browse only ([#59](https://github.com/cyanheads/gutenberg-mcp-server/issues/59)).
- **`gutenberg-guide` skill** 1.2 → 1.3: covers `catalog_rejected`, verse line breaks, and `source_notes` from RDF lookups.

## Fixed

- **`gutenberg_get_text`** reads text files over 8 MiB as four parallel byte ranges inside the same 50-second allowance, so *Webster's Unabridged Dictionary* (29765, 28,956,350 bytes) now reads. A declared size over 40 MiB fails at once with new non-retryable `text_too_large`, and HTTP 501 from the text host maps to `text_fetch_rejected` ([#61](https://github.com/cyanheads/gutenberg-mcp-server/issues/61)).
- **HTML-converted text** keeps one line per `<br>`: it emits one newline and drops the ASCII whitespace after it outside `<pre>`, so verse reads line by line (12413). The text cache key moves to `gutenberg/text/v4`, so cached text is fetched again ([#60](https://github.com/cyanheads/gutenberg-mcp-server/issues/60)).
- **Catalog fetch failures** go through one status classifier: permanent refusals (any 4xx but 408 and 429, and 501) become new non-retryable `catalog_rejected` on all four tools, except a book lookup's 404 (`not_found`) and Gutendex's past-the-last-page 404 (`page_out_of_range`). 408, 429, 5xx, timeouts, and unparsable 2xx responses stay retryable `catalog_unavailable`, so a `{}` or `null` 200 search page no longer surfaces as an internal error ([#58](https://github.com/cyanheads/gutenberg-mcp-server/issues/58)).
- **Manifests** (`server.json`, `manifest.json`, and the Claude and Codex plugin manifests) declare `GUTENDEX_BASE_URL`, `GUTENBERG_TEXT_BASE_URL`, `GUTENBERG_MIRROR_PATH`, and `GUTENBERG_MIRROR_REFRESH_CRON`; a blank or unsubstituted `${…}` value reads as unset ([#54](https://github.com/cyanheads/gutenberg-mcp-server/issues/54)).
- **Refresh cron** aborts and awaits an in-flight sync on shutdown, and skips a run while another sync holds the lock.
