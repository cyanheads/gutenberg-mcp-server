# 0.1.11 — 2026-10-16

## Changed

- **Reading limits** accept larger positive integral requests and apply existing caps locally: 50,000 characters for text, 32 books for popular browse; both surfaces report `requestedLimit` and `appliedLimit` ([#26](https://github.com/cyanheads/gutenberg-mcp-server/issues/26)).
- **Catalog metadata** adds `is_readable` for supported UTF-8/HTML editions ([#23](https://github.com/cyanheads/gutenberg-mcp-server/issues/23)) and `source_notes` for direct RDF bibliographic notes; older mirror rows and Gutendex return `null` until notes become available ([#27](https://github.com/cyanheads/gutenberg-mcp-server/issues/27)).
- **Popularity labels** identify downloads in the last 30 days at the source snapshot across catalog schemas, rendered counts, and truncation guidance ([#24](https://github.com/cyanheads/gutenberg-mcp-server/issues/24)).
- **Runtime and metadata** use Bun 1.4.2 → 1.4.3, align catalog descriptions, and synchronize framework development guidance.

## Fixed

- **HTML reading** preserves Unicode, single-pass character references, and table boundaries while excluding non-literary markup; collision-safe fences keep rendered text literal ([#21](https://github.com/cyanheads/gutenberg-mcp-server/issues/21)).
- **Mirror responses** reject empty or recognizable non-book documents before caching, tolerate incorrect content headers on legitimate books, and return sanitized permanent HTTP failures with distinct recovery reasons ([#22](https://github.com/cyanheads/gutenberg-mcp-server/issues/22)).
