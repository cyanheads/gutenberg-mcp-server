# 0.1.7 — 2026-08-22

## Added

- **Community health files** — contributor guidance and the project code of conduct now live under `.github/`.

## Changed

- **Strict tool inputs** — `@cyanheads/mcp-ts-core` `^0.12.3` makes all four root tool input schemas advertise `additionalProperties: false` and reject undeclared keys before handlers run.
- **HTTP session mode** — `.env.example`, the Docker image, and the README now explicitly select `stateless`; the example also documents `auto` and its stateful resolution.
- **Gutendex error handling** — catalog requests declare expected `404` responses and read the framework's canonical `data.body`, preserving book-not-found and out-of-range-page translations.
- **Build and typechecking** — Docker builds use Bun 1.4.0 on the builder platform and omit optional peers from production; TypeScript 7 typechecks source and tests while the build config emits source only.
- **Project guidance and tooling** — framework-managed skills, maintenance scripts, agent protocol, packaging checks, tool descriptions, and repository metadata are synchronized with the current scaffold.
- **Security contact** — vulnerability reports now use `security@caseyjhand.com`.
