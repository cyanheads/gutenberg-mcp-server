# 0.1.10 — 2026-10-08

## Changed

- **Tool error results carry a `requestId`** (`cyanheads/mcp-ts-core` 0.13.10) — error text ends with `request <id>` and `data.requestId` holds the id.
- **Error `data` no longer includes stack traces or internals** — `originalStack` and `causeChain` are gone (`cyanheads/mcp-ts-core` 0.13.7), as are request-context fields (0.13.8) and `data.rootCause` (0.13.13).
- **Numeric-string arguments are repaired before validation** (`cyanheads/mcp-ts-core` 0.13.14) — `"limit": "5"` is accepted for a number argument.
- **Tool handlers drop their explicit `ctx.recoveryFor(...)` forwards** — the framework fills the declared `recovery` hint (`cyanheads/mcp-ts-core` 0.13.10), so callers see the same hint. Covers `gutenberg_search_books`, `gutenberg_browse_popular`, and `gutenberg_get_text`; a test pins the hint on the wire.
- **Docker image runs Bun 1.4.2** (`cyanheads/mcp-ts-core` 0.13.7 scaffold pin).
- **Production dependencies install in a `deps` stage on `$BUILDPLATFORM`**, so multi-arch builds no longer run Bun under QEMU (`cyanheads/mcp-ts-core` 0.13.10). Musl-only native packages are pruned from the image (0.13.11); the catalog-mirror lifecycle scripts still ship. New `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts` drive the stage.
- **`.dockerignore` and `.gitignore` cover every `.env*` file** (`.env.example` stays tracked), and `.dockerignore` excludes the MCP Registry token files.
- **`server.json` npm entries launch via `npx`** with no `run start:*` arguments; the streamable-http entry sets `MCP_TRANSPORT_TYPE=http` (`cyanheads/mcp-ts-core` 0.13.11 shape).
- **Desktop bundle excludes `/.cache/`, `/coverage/`, `/tests/`, `/.mirror/`, and `/.scratch/`**; the npm package excludes `dist/*.mcpb`.
- **`.env.example` documents** `MCP_REQUEST_STATE_KEY`, `LOG_TOOL_FAILURE_PAYLOADS` / `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, `LOG_LLM_INTERACTIONS`, and the per-signal `OTEL_EXPORTER_OTLP_*_ENDPOINT` variables; `MCP_HTTP_HOST` defaults to `127.0.0.1`.
- **CodeQL workflow runs one job per language** under the `/language:<language>` category.
- **`package.json` `test` runs `vitest run` directly**, and `test:coverage` is new.
- **Framework scripts and skills resynced** — `lint:packaging`, `lint:mcp`, `devcheck`, `release:github`, and the skill-version check pick up the 0.13.14 versions.
- **Docs refreshed** — `CLAUDE.md`/`AGENTS.md` gain resource and prompt patterns, README Bun prerequisite and badges, and the `CITATION.cff` abstract.
